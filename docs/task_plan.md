## 🚨 P0 — 致命级（不改 = 比赛失败）

> ⚠️ 每个问题都可能独立导致比赛无法完成

### P0-1 | 🚨 Obstacle单边车道线跳过避障 ✅ 已完成
- **位置**：`obstacle.cpp:39-41`
- **症状**：弯道中一侧车道线<120像素→避障功能100%失效→锥桶直接撞击
- **比赛影响**：障碍物碰撞 -10分/次，最多可扣 -30分
- **工时**：2h（实际用了方案B完善版）
- **修复内容**：
  1. `||` → `&&` — 只两侧都严重不足才放弃避障
  2. 安全 row clamp — 防 `size_t` 下溢崩溃（空向量时 `size()-1 = SIZE_MAX`）
  3. 弱边降级 — 对侧边线<20点时锥桶也走 `curtailTracking`（防 Bezier 依赖缺失数据）
  4. resize 最小值保护 — 防车道线点数降到0
  5. 🔧 审查修复 — 分支[1][2]对称补全弱边检查、resize守卫改为检查结果值、注释修正
- **状态**：✅ 已完成（含5 Agent审查 + 3项修复）

### P0-2 | 🚨 params->results 跨线程数据竞争 ✅ 已完成
- **位置**：`icar.hpp runFsm()` + 8个FSM文件
- **症状**：AI线程(30fps)写入results，FSM线程读取——无锁保护→随机segfault，5分钟比赛崩溃概率≈98%
- **比赛影响**：进程崩溃 → DNF（0分）
- **工时**：1h
- **修复方案**：方案A — Params中添加resultsSnapshot字段，runFsm()帧首统一加锁快照
- **改动范围**：12个文件（params.hpp + icar.hpp + 8个FSM .cpp + alert段去锁）
- **状态**：✅ 已完成（经5+4两轮共9个Agent审查通过）

### P0-3 | 🚨 编码器断线→20ms全速失控（下位机） ✅ 已完成
- **位置**：`Motor.c MOTOR_Timer()` + `Motor.h` + `Encoder.c`
- **症状**：编码器线缆松动→EncoderValue=0→PID积分饱和→PWM=1500→电机全速→车冲出赛道
- **比赛影响**：物理冲出赛道 → 0分
- **工时**：3h
- **修复内容**：
  1. MotorStruct新增 PwmOutput/FaultCnt/FaultLatched 三字段
  2. MOTOR_SetPwmValue追踪实际PWM输出值
  3. 故障检测：EncoderValue==0且PwmOutput>100连续20周期(200ms)→紧急停车+errorCode|=0x10
  4. 锁存保护：触发后每周期强制PWM=0，直至系统复位
- **状态**：✅ 已完成（与P0-4联合修复，经2Agent审查+自检阻断修正）

### P0-4 | 🚨 sprintEnable绕过断线保护（下位机） ✅ 已完成
- **位置**：`Motor.c` / `Usb.c`
- **症状**：上位机断开时sprintEnable=1仍允许电机输出→完全绕过安全保护
- **比赛影响**：失控
- **工时**：2h
- **修复内容**：
  1. Motor.c MOTOR_Timer: `||`→`&&` — 必须同时满足(冲刺或自检)+上位机连接
  2. Usb.c USB_Edgeboard_Timr: 掉线时清除sprintEnable+SpeedSet=0
- **状态**：✅ 已完成（与P0-3联合修复，经2Agent审查）

### P0-5 | 🚨 舵机掉线不回中（下位机） ✅ 已完成
- **位置**：`Usb.c USB_Edgeboard_Timr()`
- **症状**：上位机掉线后舵机保持最后一帧角度→车跑偏/原地转圈
- **比赛影响**：无法控制方向
- **工时**：1h
- **修复**：掉线时执行 `SERVO_SetPwmValueCorrect(servoStr.thresholdMiddle)` 回中
- **状态**：✅ 已完成（1Agent审查通过）

## 🔴 P1 — 严重级（大幅扣分）

### P1-1 | 🔴 sendHeart 发送未初始化数据
- **位置**：`client.hpp:277`
- **症状**：心跳包使用未初始化的内存数据→通信异常
- **比赛影响**：上下位机通信不稳定
- **工时**：0.5h
- **修复**：显式填充4字节心跳包 [0x42][0x00][4][checksum]
- **状态**：⬜ 未开始

### P1-2 | 🔴 lineArea 从未赋值→动态调速失效
- **位置**：`center.cpp`
- **症状**：lineArea=死代码，turnD=3.5过高→舵机抖动
- **比赛影响**：过弯不减速+抖动→冲出赛道 -5分
- **工时**：2h
- **修复**：lineArea正确赋值计算弯道面积；turnD降低至1.5-2.0
- **状态**：⬜ 未开始

### P1-3 | 🔴 终点停车无距离测量
- **位置**：`cross.cpp`
- **症状**：斑马线触发STOP后 `exit(0)` 杀进程，无距离反馈→停车精度随机
- **比赛影响**：停车>1.5m不给分；exit(0)裁判不认可 -5分
- **工时**：4h
- **修复**：编码器积分估算距离，距斑马线1.5m内刹车，不发exit(0)改为停车状态上报
- **状态**：⬜ 未开始

### P1-4 | 🔴 Slow慢行区无超时退出
- **位置**：`slow.cpp`
- **症状**：UNLIMIT解除标志漏检（概率10-20%）→永久锁在0.35m/s
- **比赛影响**：无法完赛
- **工时**：0.5h
- **修复**：增加超时计数器（如10秒无UNLIMIT确认→自动恢复速度）
- **状态**：⬜ 未开始

### P1-5 | 🔴 30秒超时不恢复自动模式
- **位置**：`manualControl.cpp:289`
- **症状**：施工区手动接管超时→emergencyStop→manualTakeover仍为true→永久卡死
- **比赛影响**：施工区永久停车 → 无法完赛
- **工时**：1h
- **修复**：超时后复位 manualTakeover=false，恢复自动驾驶
- **状态**：⬜ 未开始

### P1-6 | 🔴 上位机不接收下位机遥测数据
- **位置**：上位机通信层
- **症状**：不读取电池电压/编码器速度/自检状态→纯盲开
- **比赛影响**：低电量不告警、失速不知道、故障无视
- **工时**：2h
- **修复**：补全遥测帧解析，上位机读取并记录/告警
- **状态**：⬜ 未开始
