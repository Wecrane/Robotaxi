# 🧠 YOLOv3 模型训练速查

## 整体流程

```
采集图片 → EasyData标注 → AI Studio训练 → Docker编译 → 部署到小车
 (1天)       (1天)         (1-2天)        (半天)        (10分钟)
```

---

## 1. 采集图片

用小车的摄像头拍摄赛道元素，每个类别 **50-100 张**：

☐ 限速指示牌（红色/黑色）   ☐ 停车场指示牌
☐ 自动道闸                 ☐ 施工区指示牌  
☐ 锥桶（74mm×74mm）        ☐ 行人（站立/行走/奔跑）
☐ 启停斑马线               ☐ 停车位
☐ 停靠点                   ☐ 岔路口
☐ 路肩

---

## 2. EasyData 标注

1. 登录 https://ai.baidu.com/easydata/
2. 创建数据集 → **物体检测** → **矩形框标注**
3. 上传图片压缩包
4. 添加标签列表（上面的13种类别）
5. 逐张框选标注
6. 导出格式：**XML**（Pascal VOC）

## 3. AI Studio 训练

```bash
# Fork 赛曙开源项目（推荐）或自行创建

# 启动 GPU 环境后：
cd ~/work
# 下载 PaddleDetection 2.4.0 并解压到 work/

cd ~/work/PaddleDetection
pip install -r requirements.txt
python setup.py install

# 解压数据集
unzip -oqd /home/aistudio/work/PaddleDetection/dataset/voc/ 你的数据集路径

# 修改 voc.yml（数据集路径）
# 修改 yolov3_reader.yml（输入尺寸 → 320×320）

# 启动训练
python tools/train.py \
  -c configs/yolov3/yolov3_mobilenet_v1_ssld_270e_voc.yml \
  --eval

# 导出模型
python tools/export_model.py \
  -c configs/yolov3/yolov3_mobilenet_v1_ssld_270e_voc.yml \
  -o weights=output/yolov3_mobilenet_v1_ssld_270e_voc/best_model.pdparams \
  --output_dir=output_inference
```

## 4. Docker 编译

```bash
# Windows 前提：启用 Hyper-V + 安装 Docker Desktop

# 拉取编译镜像
docker load -i ppnc2.0_v1.0.2.tar

# 启动容器（把 D:\work 换成你的工作目录）
docker run -it --cap-add=SYS_PTRACE --name ppnc2.0_docker \
  -v D:\work:/home/edgeboard/workspace ppnc2.0:v1.0.2 /bin/bash

# 容器内每次都要执行：
export PPNC_HOME=/usr/local/ppnc
source /usr/local/ppnc/scripts/activate_env.sh

# 准备文件：
# work/yolov3/model/ ← model.pdmodel + model.pdiparams
# work/yolov3/image/ ← 50张训练图片（校准用）
# work/tools/        ← 编译工具

# 修改配置后编译：
cd /home/edgeboard/workspace/tools/
python3 compile.py ./config.json
```

编译输出：`tools/build/inference.zip`
