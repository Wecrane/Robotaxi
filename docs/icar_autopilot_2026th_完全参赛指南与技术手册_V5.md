## 2. 赛道元素详解

### 2.1 完整赛道元素清单（13种）

| #   | 元素             | 规格/特征                    | 识别方法   | 通过规则                    |
| --- | ---------------- | ---------------------------- | ---------- | --------------------------- |
| 1   | **限速指示牌**   | 红色=限速开始，黑色=解除限速 | YOLOv3检测 | 限速区≤0.4m/s，违者扣分     |
| 2   | **测速装置**     | 物理传感器测速               | 传感器触发 | 验证限速通过速度            |
| 3   | **停车场指示牌** | 指示停车场入口位置           | YOLOv3检测 | 识别后按指令进入停车场      |
| 4   | **自动道闸**     | 默认关闭，到达自动打开       | YOLOv3检测 | 停车等待道闸开启后通过      |
| 5   | **停车场车位**   | 1-4号车位，按指令停靠        | YOLOv3检测 | 正确车位停靠（未压线）+10分 |
| 6   | **施工区指示牌** | 指示施工路口                 | YOLOv3检测 | 到达后停车+警报             |
| 7   | **施工区**       | 红色虚线标注，道路缺失       | 视觉检测   | **强制手动接管**            |
| 8   | **停靠点**       | 4个停靠点，按指令选择        | YOLOv3检测 | 正确位置停靠（未压线）+10分 |
| 9   | **锥桶**         | 74mm×74mm                    | YOLOv3检测 | 需绕行避障，碰撞-10分       |
| 10  | **行人**         | 塑料人偶（站立/行走/奔跑）   | YOLOv3检测 | 需绕行+鸣笛，碰撞-10分      |
| 11  | **启停斑马线**   | 起点/终点标志                | YOLOv3检测 | 终点停车斑马线后1.5m内+5分  |
| 12  | **岔路口**       | T形/卜型/丁字                | 视觉检测   | 根据大模型指令选择左/右     |
| 13  | **路肩**         | 道路边界                     | 视觉检测   | 不可逾越，3轮以上出界-20分  |

## 3. 比赛流程与评分

### 3.1 正式比赛流程（10分钟/场，3圈）

```
起点斑马线发车 → 大模型理解指令 →
第1圈：自动行驶+识别停车场→按指令泊车→驶出 →
第2圈：识别施工区→停车警报→手动接管→施工区出口停靠→驶出 →
第3圈：识别岔路口→选择路径→停靠→终点斑马线停车→完成
```

### 3.2 三圈配置（对照config.json）

| 圈次        | 主要状态机                         | 关键任务             |
| ----------- | ---------------------------------- | -------------------- |
| 第1圈(lap1) | park, stop, slow, cross, station   | 停车场泊车(1-4号位)  |
| 第2圈(lap2) | busy, manual, slow, cross, station | 施工区手动接管+停靠  |
| 第3圈(lap3) | yfork, slow, cross, station, stop  | Y型岔路右侧+终点停车 |

### 3.3 评分标准

**加分项：**

| 项目                         |  分值  |
| ---------------------------- | :----: |
| 多模态大模型识别指令         |  +15   |
| 正确选择路口方向             | +10/次 |
| 识别物体后正确鸣笛           | +5/次  |
| 施工区手动接管               |  +15   |
| 施工区停靠（正确位置未压线） |  +10   |
| 停车场停靠（正确位置未压线） |  +10   |
| 岔路口停靠（正确位置未压线） |  +10   |
| 限速行驶（≤0.4m/s）          | +5/次  |
| 终点停车（斑马线后1.5m内）   |   +5   |

**扣分项：**

| 违规行为                  |     扣分     |
| ------------------------- | :----------: |
| 碰撞锥桶/行人 → 倾倒/移位 |    -10/次    |
| 逆行/停止/3轮出界/失控    | -20+强制重试 |
| 施工区未手动接管          |  直接判违规  |
| 限速区超速                |    -5/次     |

```bash
  -c configs/yolov3/yolov3_mobilenet_v1_ssld_270e_voc.yml \
  --eval

python tools/export_model.py \
  -c configs/yolov3/yolov3_mobilenet_v1_ssld_270e_voc.yml \
  -o weights=output/best_model.pdparams \
  --output_dir=output_inference
```

### 11.1 主入口层

**icar.cpp** — 程序入口：

- 创建Icar对象（触发全部初始化），30fps主循环
- 帧率控制：`sleep_for(33ms - elapsed)`

**icar.hpp** — 主控门面类（~600行）：

- FsmFactory聚合9个FSM实例+手动控制线程
- 构造函数：80行初始化（Params→Center→Motion→Predeal→Detection→Client→Capture→FSM→Loops→ManualThread）

**client.hpp**（~300行）：

- TCP↔UART桥接器

## 13. 上下位机协议对偶分析

### 13.1 帧协议定义

```
通用帧格式: [0x42][ADDR][LEN][DATA...][checksum]
帧头: 0x42 | 帧长范围: 4-30(下位机) / 4-12(上位机)
校验: 8位累加和(覆盖byte[0..LEN-2],存放于byte[LEN-1])
字节序: 双方均为ARM小端(IEEE 754 float32, uint16 LE)
```

### 13.2 地址码双向支持矩阵

|   Addr   | 名称           | 下→上 | 上→下 |       状态       |
| :------: | -------------- | :---: | :---: | :--------------: |
|   0x00   | HEART          |  ❌   |  ✅   |       单向       |
| **0x01** | **CONTROL**    |  ❌   |  ✅   | ⭐唯一完美控车帧 |
|   0x02   | SPEEDMODE      |  ❌   |  ❌   |       🔴死       |
|   0x03   | SERVOTHRESHOLD |  ✅   |  ❌   |      🔴半残      |
|   0x04   | BUZZER         |  ❌   |  ✅   |       单向       |
|   0x05   | LIGHT          |  ❌   |  ❌   |       🔴死       |
|   0x06   | KEYINPUT       |  ✅   |  ❌   |    ⚠️语义断裂    |
|   0x07   | BATTERY        |  ✅   |  ❌   |     🔴上丢弃     |
|   0x08   | SPEEDBACK      |  ✅   |  ❌   |     🔴上丢弃     |
|   0x0A   | INSPECTOR      |  ❌   |  ❌   |       🔴死       |
|   0x0B   | SELFCHECK      |  ✅   |  ❌   |     🔴上丢弃     |
|   0x10   | KEY            |  ❌   |  ❌   |       🔴死       |

**统计: 0个完全双向, 3个单向通畅, 10个死地址(59%)**

### 13.3 ADDR_CONTROL(0x01) — 唯一正确帧

```
[0x42][0x01][0x0A][speed_float32_LE×4字节][servo_uint16_LE×2字节][checksum]
```

上下位机字节级100%验证通过：帧头/地址/帧长/float32小端/uint16小端/累加和校验全一致。
